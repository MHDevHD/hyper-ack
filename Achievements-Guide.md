# HYPER ACK — Main Game Achievements

## Score milestones

| Achievement | Description | Tip |
|---|---|---|
| **First Blood** | Score your first 10 points. | Happens in the first couple seconds of any run. |
| **Triple Digits** | Reach a score of 100. | Any mode counts, just keep clearing packets. |
| **Four Figures** | Reach a score of 1000. | Needs a decent run length. Time Attack or a mid-length Normal run both work. |
| **High Roller** | Reach a score of 5000 in a single run. | Best chased in Normal or Hyper where runs can go long. Needs sustained survival, not just one good streak. |

## Survival & skill

| Achievement | Description | Tip |
|---|---|---|
| **One Minute Man** | Survive a single run for 60 seconds. | Works in any mode. Hardcore is the tightest squeeze since one hit ends it. |
| **Untouchable** | Finish a run without taking a single hit. | Only unlocks when a run reaches its natural end, and taking the hit that ends a lives-based run would also break "no hit." So Time Attack is the realistic path: survive the full 90 seconds flawlessly and the timer ends the run for you, no hit required. |
| **Flawless** | Clear a full level without taking a hit. | Per level, not per run. Resets each level, so one clean level anywhere is enough. |
| **Wave Rider** | Survive a boss wave. | Boss waves can appear randomly from level 2 onward in most modes, or are forced every level in Boss Rush. |
| **On a Roll** | Reach a 10-hit streak. | Chain good hits without letting one through or missing a bad one. |
| **Unstoppable** | Reach a 25-hit streak. | Same idea, longer. Normal mode's steadier pace makes this easier than Hyper. |
| **Legendary** | Reach a 50-hit streak. | A long, clean run. Normal or Time Attack give the most consistent spawn pacing to sustain this. |

## Mode-specific

| Achievement | Description | Tip |
|---|---|---|
| **Against The Clock** | Score 500+ in a single Time Attack run. | Time Attack is a 90 second clock, so maximize score before it runs out. |
| **Photo Finish** | Score 1000+ in a single Time Attack run. | Same mode, higher bar. Needs a near-optimal 90 seconds. |
| **One Shot, One Kill** | Reach level 3 in Hardcore mode. | Hardcore is one life, no second chances. |
| **Hardcore Veteran** | Reach level 5 in Hardcore mode. | Same mode, further in. |
| **Storm Chaser** | Reach level 3 in Boss Rush mode. | Boss Rush makes every level a forced boss wave. |
| **Category Five** | Reach level 5 in Boss Rush mode. | Same mode, further in. |
| **Gone Rogue** | Score 200+ in a single Red Team run. | Red Team reverses targets, so you're hitting the bad packets and dodging the good ones. |
| **Double Agent** | Score 500+ in a single Red Team run. | Same mode, higher bar. |
| **Muscle Memory** | Reach level 3 in Reverse Proxy mode. | Reverse Proxy is Normal mode with every control inverted. |
| **Autopilot** | Reach level 5 in Reverse Proxy mode. | Same mode, further in. |
| **Pacifist Rebellion** *(joke achievement)* | Finish a Red Team run without ever catching a bad packet. | Survive to a natural run end in Red Team with a score of exactly 0. Never go after what the mode is asking you to hit. |
| **Wrong Way** *(joke achievement)* | Lose all your lives within 5 seconds of a Reverse Proxy run. | Inverted controls claim most players almost instantly, so this one tends to happen by accident on a first attempt. |

## Hyper mode

Hyper lets you pick a starting speed from x2 to x8. Each whole-number speed has its own "survive and score" achievement for reaching 500+ score in a single run at that starting speed:

| Starting speed | Achievement |
|---|---|
| x2 | **Cold Start** |
| x3 | **Overclocked** |
| x4 | **Full Throttle** |
| x5 | **Breakneck** |
| x6 | **Critical Mass** |
| x7 | **Escape Velocity** |
| x8 | **Redline** |

| Achievement | Description | Tip |
|---|---|---|
| **Terminal Velocity** | Survive 60 seconds in a Hyper Mode run starting at x6 speed or higher. | Combine the speed and survival requirements in one run. Pick x6, x7, or x8 and just last a minute. |

## Lifetime / cumulative

| Achievement | Description | Tip |
|---|---|---|
| **Data Hoarder** | Rack up 100,000 cumulative points across all runs. | Tracked in the background forever. Progress shows live in the Achievements panel once you're close, and every mode's score counts toward the total. |
| **Creature of Habit** | Play 100 runs. | Counts every completed run across all modes. Also shows live progress in the Achievements panel. |

## Misc

| Achievement | Description | Tip |
|---|---|---|
| **Say Cheese** | Take your first screenshot. | Press **F7** during a run to capture and save a screenshot. Unlocks on the very first one. |
| **Night Owl** | Start a run between midnight and 4 AM. | Checked against your system clock the moment a run starts. Just play late, or set your clock if you're impatient. |
| **Full Access** | Unlock every game mode. | Work through the mode-unlock chain: Time Attack (reach level 5 in Normal), then Hardcore (survive a full Time Attack run), then Boss Rush (reach level 5 in Hardcore). Separately, Red Team and Reverse Proxy both unlock off Normal mode level milestones. |

## Background themes (Normal Mode)

Every non-default theme has a matching achievement, named `(Normal Mode) <theme name>` on Steam. All of them track your **Normal mode** best stats specifically, so Hyper, Hardcore, Time Attack, and the rest don't count toward any of these.

| Theme | Requirement |
|---|---|
| **(Normal Mode) Amber CRT** | Survive a single Normal mode run for 10 minutes. |
| **(Normal Mode) Deep Purple** | Reach level 5 in Normal mode. |
| **(Normal Mode) Blueprint** | Reach a score of 2500 in Normal mode. |
| **(Normal Mode) Threshold 100 through 10000** | 24 separate score-tier themes, each unlocked by reaching that score in Normal mode: 100, 250, 500, 750, 1000, 1250, 1500, 1750, 2000, 3000, 3500, 4000, 4500, 5000, 5500, 6000, 6500, 7000, 7500, 8000, 8500, 9000, 9500, 10000. |
| **Collector** | Unlock every background theme (every achievement above, all at once). |

**Tip:** since all of these read off Normal mode's all-time best score, level, and longest run, grinding Normal mode is the most efficient way to unlock the whole theme set. A few long, careful Normal runs will knock out several score tiers at once as your high score climbs.
